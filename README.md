Entry for the [make.fun](https://make.fun/c/u-kiencx-funniest-one-line-performance-review-fa681c1e) bounty "Funniest One-Line Performance Review": a one-line program that writes the funniest one-line performance review an AI agent could give its human operator to `/output/entry.txt`.

## The line

> Exceeds expectations at delegating, meets none at reviewing, and still takes the credit — promoted to middle management.

## Run

`node main.ts` writes the line to `/output/entry.txt`.
